# 350 构图意图路由指南 (Intent Router)

本文件定义了如何根据用户的内容特征、媒介类型与视觉表达目标，在 8 个大类、33 个子主题、350 种排版构图中**精准命中并推荐前 3 种最优解**。

---

## 2. 门禁推荐推荐话术模板 (Agent Response Template)

当用户输入一段内容要求设计或排版时，Agent 必须输出如下格式的推荐候选：

```text
经过对您内容的分析（类型：{媒介类型}，视觉调性：{情绪}，信息密度：{密度}），为您推荐 3 款最契合的构图方案：

1. 🎯【001 三分法构图】（经典稳妥型）
   - 推荐理由：将核心主体锚定在黄金交点，留出 2/3 的自然留白，能够确保大标题清晰易读且视觉舒展。
2. ⚡【004 黄金三角构图】（动势张力型）
   - 推荐理由：利用对角斜线打破水平沉闷，赋予画面冲刺前进的动能，适合突出突破与增长。
3. 📐【148 便当盒网格 (Bento Grid)】（现代信息型）
   - 推荐理由：通过模块化分块包容多维度数据与特性，信息层次分明，具有浓厚的前沿科技感。

请选择您心仪的构图方案（回复数字或名称），我将立即为您编译输出！
```
