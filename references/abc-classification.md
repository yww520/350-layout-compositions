# 350 张原版图逐编号 ABC 分档清单

> 分类依据：✅ = 亲自查看缩略图判定 | 📎 = 基于同子类规律推断 | 🔲 = 无缩略图,按子类推断
>
> **A档** = 纯几何/线框/图表,HTML+CSS+SVG 可精确复刻
> **B档** = 含扁平风格插画(剪影/山峰/建筑轮廓等),SVG 可近似但需手绘 path 或 AI 辅助
> **C档** = 含摄影/复杂渐变/水墨/3D,必须用 AI (小云雀) 生成位图
